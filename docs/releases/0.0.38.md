# 0.0.38

## English

### New
- Remote control over TCP (loopback only, 127.0.0.1), compatible with the StationPlaylist command set, so a hardware desk bridge (for example the MR18 + X-TOUCH bridge) can drive SARA. Commands run the same actions as keyboard shortcuts, in the GUI thread. Protocol: `docs/sterowanie-tcp.md`.
- The desk always controls the main music playlist chosen in Options, not the focused panel.
- Hold: the bridge can stop automatic transitions while a microphone is on air (`Hold`, `Hold=1`, `Hold=0`).
- Play in manual mode works like Enter on the main playlist (queue first, otherwise the highlighted track).
- Mix point editing from the desk (Mix commands) with PFL preview, sharing one session with the mix points dialog. The jog wheel stops at the track edge and wraps to the other end only after a pause; points never go past the track length.
- `Rem` counts to the transition, exactly like Ctrl+Alt+T. New `Players` command reports which players of the main playlist are active.
- Automatic loudness normalization (EBU R128) of new playlist tracks with true peak protection.

### Fixes
- Mix and loop timing is deterministic: one trigger path, fades driven by stream position, native loop wrap, loop end clamped to the stream length, no monitor thread leak.
- Ready (preloaded) streams are reused for mixes and the manual queue, so the next track starts without delay.
- `stop()` no longer waits for an active fade.
- StationPlaylist tags: unset points (`-1`) are treated as unset, Segue (APE and ID3 TXXX) is read as absolute file time, and SARA's own mix tags win over foreign ones.
- Mix points at the same position (Cue = Intro) are accepted from the desk, like in the dialog.
- `Helo` reports the version of the running code, not stale installation metadata.

## Polski

### Nowe
- Sterowanie przez TCP (tylko 127.0.0.1), zgodne z poleceniami StationPlaylist, dla mostka stołu (np. MR18 + X-TOUCH). Polecenia wywołują te same akcje co skróty klawiszowe, w wątku okna. Opis: `docs/sterowanie-tcp.md`.
- Stół steruje zawsze główną playlistą muzyczną wybraną w Opcjach, niezależnie od fokusu.
- Hold: mostek wstrzymuje automatyczne przejścia, gdy mikrofon jest na antenie.
- Play w trybie ręcznym działa jak Enter na głównej playliście.
- Edycja punktów miksu ze stołu z odsłuchem PFL, wspólna sesja z oknem punktów miksu. Kółko zatrzymuje się na brzegu utworu i przeskakuje na drugi koniec dopiero po przerwie; punkty nie wychodzą poza długość utworu.
- `Rem` liczy do przejścia jak Ctrl+Alt+T. Nowe polecenie `Players` podaje numery grających odtwarzaczy głównej playlisty.
- Automatyczne wyrównanie głośności (EBU R128) nowych utworów z ochroną szczytów.

### Poprawki
- Deterministyczne miksy i pętle: jedna ścieżka wyzwalania, wyciszenie liczone pozycją strumienia, natywne zawijanie pętli, koniec pętli przycięty do długości, bez wycieku wątku monitora.
- Gotowy (preładowany) strumień jest używany przy miksie i kolejce ręcznej, więc następny utwór startuje bez opóźnienia.
- `stop()` nie czeka na trwające wyciszenie.
- Tagi StationPlaylist: nieustawione punkty (`-1`) są pomijane, Segue (APE i ID3 TXXX) liczony od początku pliku, własne tagi SARY mają pierwszeństwo.
- Stół przyjmuje punkty miksu w tym samym miejscu (Cue = Intro), tak jak okno.
- `Helo` podaje wersję działającego kodu.
